# Usage profile: what you work with

> User Manual → Chapter "First use" → new section after "Language and level"; and Chapter "Home screen" → new section "Profile".

Someone who only runs one type of exam does not need to see the screens of
the others. The **usage profile** says what you work with and decides:

- which exams the home screen offers (and the *Change* dialog);
- which tabs appear in the program window;
- in the Complete level, which charts (panels) start out open.

**Ready-made profiles:** *Brain (EEG)*, *Muscles (EMG)*, *Heart (ECG)*,
*Eyes (EOG)* and *Everything*. The *Everything* profile hides nothing: it is
the way the program has always been. Anyone who already used ROA stays in
*Everything* after updating.

**On first use**, the *What do you work with?* page shows four large cards
(brain, muscles, heart, eyes). Tick everything you use:

- one card → the ready-made profile for that exam;
- two or three → the custom profile *My bench*, with only those exams;
- all four → *Everything*.

On the Complete (research) path there is also the *Choose the charts* page:
the charts recommended for your profile come already ticked; untick what you
do not want to see. This can be changed later at any time with the *Panels*
button of each tab.

**Changing profile.** On the home screen there is the *Profile:* line (in
both levels). The change applies at once: the exams outside the profile
disappear from the screen and, if the exam in use left the profile, the
program switches to the first exam of the new profile. In *System → Settings
→ Theme and Colors → Usage profile* you can also **create, duplicate, rename
and delete** profiles and tick the exams of a custom profile (the ready-made
ones cannot be renamed or deleted; duplicate one to edit it).

**Recordings of another exam.** Opening a recording made in another type of
exam keeps working normally in *Open a recording*, even if that exam is not
in your profile.
