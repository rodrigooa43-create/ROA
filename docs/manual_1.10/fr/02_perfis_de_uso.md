# Profil d'utilisation : avec quoi vous travaillez

> Manuel de l'utilisateur → Chapitre « Première utilisation » → nouvelle section après « Langue et niveau » ; et Chapitre « Écran d'accueil » → nouvelle section « Profil ».

Qui ne fait que des examens d'un seul type n'a pas besoin de voir les écrans des
autres. Le **profil d'utilisation** dit avec quoi vous travaillez et décide :

- quels examens l'écran d'accueil propose (et la boîte de dialogue *Changer*) ;
- quels onglets apparaissent dans la fenêtre du programme ;
- au niveau Complet, quels graphiques (panneaux) s'ouvrent d'emblée.

**Profils prêts :** *Cerveau (EEG)*, *Muscles (EMG)*, *Cœur (ECG)*,
*Yeux (EOG)* et *Tout*. Le profil *Tout* ne cache rien : c'est le programme tel
qu'il a toujours été. Qui utilisait déjà ROA reste dans *Tout* après la mise à
jour.

**À la première utilisation**, la page *Avec quoi travaillez-vous ?* montre
quatre grandes cartes (cerveau, muscles, cœur, yeux). Cochez tout ce que vous
utilisez :

- une carte → le profil prêt de cet examen ;
- deux ou trois → le profil personnalisé *Mon établi*, avec ces examens
  seulement ;
- les quatre → *Tout*.

Dans le parcours Complet (recherche), il y a aussi la page *Choisissez les
graphiques* : les graphiques recommandés pour votre profil sont déjà cochés ;
décochez ce que vous ne voulez pas voir. Cela peut être modifié à tout moment
par le bouton *Panneaux* de chaque onglet.

**Changer de profil.** Sur l'écran d'accueil se trouve la ligne *Profil :* (aux
deux niveaux). Le changement vaut immédiatement : les examens hors du profil
disparaissent de l'écran et, si l'examen en cours est sorti du profil, le
programme passe au premier examen du nouveau profil. Dans *Système → Paramètres
→ Thème et Couleurs → Profil d'utilisation*, vous pouvez aussi **créer,
dupliquer, renommer et supprimer** des profils et cocher les examens d'un profil
personnalisé (les profils prêts ne peuvent être ni renommés ni supprimés ;
dupliquez-en un pour le modifier).

**Enregistrements d'un autre examen.** Ouvrir un enregistrement réalisé dans un
autre type d'examen continue de fonctionner normalement dans *Ouvrir un
enregistrement*, même si cet examen n'est pas dans votre profil.
