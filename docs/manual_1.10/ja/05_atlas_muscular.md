# 筋肉アトラス：各電極の位置

> ユーザーマニュアル → 「筋肉の検査」の章 → 「筋肉アトラスと電極の配置」の節を置き換え。

体の図は描き直されました。医学イラスト風の線画による全身が、**正面**、**背面**、**側面**から描かれ、さらに拡大された**部位**（顔、首、胸と腹部、背中、上腕、前腕と手、手、脚と足 — それぞれ右側と左側）があります。ビューまたは部位は *ビュー* ボックスで選びます。シンプルレベルでは、同じ図が「電極の位置 (体の図)」として表示されます。

**電極を置く。** *電極を追加* をクリックし、次に体の上をクリックします。点は最も近い筋肉の**推奨位置に吸着する**か（SENIAMの参照による筋腹；顔では咬筋、側頭筋、前頭筋、眼輪筋、頬骨筋）、クリックした場所にそのまま置かれます。各電極は番号付きの点です。ドラッグで移動、ダブルクリックで名前の変更、*Delete* で削除します。拡大された部位に置いた電極は、全身の図にも表示されます。

**活動を見る。** 検査中、筋肉の強さが**電極の点に**、大きくなり熱くなるヒートスポット（青 → 黄 → 赤）として表示され、体の輪郭で切り抜かれます。番号の周りのリングは信号の品質を示します。

以前のバージョンで作ったモンタージュはそのまま有効です。電極は、筋肉、チャンネル、名前を失うことなく新しい図に変換されます。
