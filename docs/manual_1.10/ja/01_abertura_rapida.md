# プログラムを開く（起動画面）

> ユーザーマニュアル → 「インストールと初回起動」の章 → 「プログラムを開く」の後。

ROAを開くと、ロゴと、描かれていく信号の線が表示された小さな画面が現れます。その下には、プログラムが今何をしているかが言葉で表示されます（「ライブラリを読み込んでいます…」「ホーム画面を準備しています…」）。この画面はホーム画面の準備ができると自動的に消えます。何もクリックする必要はありません。

**インストールまたは更新後の初回起動。** プログラムは一度だけ準備を行い（画面には「初めてプログラムを準備しています…」と表示されます）、その結果をプログラムの隣にある `.roa_cache` フォルダに保存します。次回以降の起動はずっと速くなります。プログラムのフォルダに書き込みができない場合（たとえば `Program Files` の中にある場合）、キャッシュはユーザーのフォルダ（`%LOCALAPPDATA%\ROA\cache`）に置かれます。このフォルダを削除しても問題はありません。次回の起動時に作り直されます。

**起動画面が邪魔になる場合**（たとえば自動化処理や、映像に問題のあるコンピュータでは）、`--sem-splash` オプションを付けてプログラムを開くか、環境変数 `ROA_SEM_SPLASH=1` を設定してください。

**更新。** *ヘルプ → 更新を確認* では、プログラムは引き続き自分自身のコードだけをダウンロードし、あなたのデータを送信することは決してありません。このバージョンからは、更新に新しいランチャー（`EEG_Data_Collector.py`）が含まれている場合、ランチャーも更新できるようになりました。更新できなかった場合は通知が表示され、プログラムは現在のランチャーのまま動作を続けます。
