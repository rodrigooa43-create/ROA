# 使用プロファイル：どの検査を扱うか

> ユーザーマニュアル → 「初めての使用」の章 → 「言語とレベル」の後の新しい節；および「ホーム画面」の章 → 新しい節「プロファイル」。

一種類の検査しか行わない人が、他の検査の画面を見る必要はありません。**使用プロファイル**は、あなたがどの検査を扱うかを示し、次のことを決めます。

- ホーム画面（および *変更* ダイアログ）が提供する検査
- プログラムのウィンドウに表示されるタブ
- 完全レベルでは、最初から開いた状態で表示されるグラフ（パネル）

**既定のプロファイル：** *脳 (EEG)*、*筋肉 (EMG)*、*心臓 (ECG)*、*目 (EOG)*、*すべて*。プロファイル *すべて* は何も隠しません。これまでのプログラムと同じ状態です。以前からROAを使っていた人は、更新後も *すべて* のままです。

**初めての使用時**には、ページ *どの検査を行いますか？* に四つの大きなカード（脳、筋肉、心臓、目）が表示されます。使うものをすべてチェックしてください。

- カード一つ → その検査の既定のプロファイル
- 二つまたは三つ → それらの検査だけを含むカスタムプロファイル *マイベンチ*
- 四つすべて → *すべて*

完全（研究）の経路には、さらにページ *グラフを選ぶ* があります。あなたのプロファイルに推奨されるグラフにはあらかじめチェックが入っています。見たくないものはチェックを外してください。これは後からいつでも、各タブの *パネル* ボタンで変更できます。

**プロファイルの切り替え。** ホーム画面には *プロファイル：* の行があります（両方のレベルで）。切り替えはすぐに反映されます。プロファイル外の検査は画面から消え、使用中の検査がプロファイルから外れた場合、プログラムは新しいプロファイルの最初の検査に移ります。*システム → 設定 → テーマとカラー → 使用プロファイル* では、プロファイルの**作成、複製、名前の変更、削除**や、カスタムプロファイルに含める検査の指定もできます（既定のプロファイルは名前の変更も削除もできません。編集するには、どれかを複製してください）。

**別の検査の記録。** 別の種類の検査で作られた記録を開くことは、その検査があなたのプロファイルに含まれていなくても、*記録を開く* でこれまでどおり行えます。
