# リプレイ：記録をアニメーションで見る

> ユーザーマニュアル → 「記録を見直す」の章 → 新しい節「リプレイ」（「PDF 報告書」の後）。

**筋肉**、**心臓**、**目**の記録を開くと、ボタン **▶ リプレイ** が使えるようになります（脳の記録では無効のままです）。三つの検査に共通のプレーヤーを備えたウィンドウが開きます：**▶ 再生 / ⏸ 一時停止**、**⏮ 先頭**、ドラッグできるタイムライン、そして「0:05 / 0:30」の時計です。完全レベルでは、速度（0.25× から 4×）と *リピート* もあります。

> アニメーションは記録された内容を**再現（シミュレーション）**したものです。本人の映像ではなく、報告書でも診断でもありません。ウィンドウ上部のラベルにも同じことが書かれています。

## 筋肉

側面から見た関節のある人形（胴体、肩、肘、前腕、手首、指のある手）が、タイムラインに**マークされた動作**を再現し、各筋肉はその瞬間に測定された強さで光ります。回外と回内は見間違えようがありません。明るい手のひらが上を向くか、手の甲が下を向き、「手のひらを上に／下に」というテキストが添えられます。

タイムライン（2〜4トラック）は記録の**マーカーとフェーズ**（「屈曲」「伸展」「安静」…）から作られます。マーカーがない場合は、**検出された収縮**が「未設定」の区間になります。同じ瞬間にあるトラックは**重ね合わされます**（たとえば、肘を曲げながら手を閉じる）。使える動作：肘の屈曲と伸展、回外、回内、手関節の屈曲と伸展、手を開く・閉じる、つまみ、肩の屈曲と伸展、安静。

**シンプル**レベルでは、プレーヤー、人形、区間のリストが表示されます。**完全**レベルではタイムラインを編集できます。ブロックをドラッグして移動、端を引っ張って伸ばし、右クリックで *動作を変更*、*ここで分割*、*削除*、*トラックを追加／削除*。Ctrl+Z で元に戻せます。*既定のタスク* は、カーソル位置から、手に物を持った一連の動作を挿入します：**ダンベルを持ち上げる**、**鍵でドアを開ける／閉める**、**机の上のコップを取って口に運ぶ**。活動している筋肉が選ばれた動作と合わないとき（たとえば屈曲の区間で上腕三頭筋が活動している）、警告が表示されます。*保存* は記録の隣に `movimentos.json` を書き込みます。閉じるときに未保存のマークがあれば、プログラムが確認します。

## 心臓

描かれた心臓が、カーソル付きの波形と毎分の拍動数の隣で、**記録されたリズムで拍動します**。下のバンドには**すべて**の拍が表示されます。規則的な拍は細い線、**早い拍**はオレンジ色の三角形、**長めの休止**は赤い中空の長方形です（色と形の両方で示すので、色の見分けが難しい人にも分かります）。言葉によるリスト（「0:13 早い拍」「0:25 長めの休止 (1.7 s)」）はクリックでき、プレーヤーをその位置に移動します。拍は PDF 報告書のものと同じです。完全レベルでは、バンド上での右クリックで**修正**ができます（拍を削除、ここに拍を追加、規則的な拍／早い拍／長めの休止として印を付ける）。*保存* は `batidas.json` を書き込みます。

## 目

描かれた二つの目が、**まばたきのときにまばたきし**、信号が示す方向を**見ます**。*水平反転* と *垂直反転* は左右・上下を入れ替えます。電極が逆に貼られていた場合のためです。タイムラインは起きたことを言葉で示し（「0:03 まばたき」「0:05 右を見た」）、カウンターはまばたきと、左右および上下への動きを集計します。完全レベルでは、リスト上での右クリックでイベントを削除したり方向を変更したりできます。*保存* は `olhos.json` を書き込みます。
