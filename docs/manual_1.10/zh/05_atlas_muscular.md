# 肌肉图谱：每个电极在哪里

> 用户手册 → “肌肉检查”一章 → 替换“肌肉图谱与电极放置”一节。

人体示意图已重新绘制：一个医学插画线条风格的完整人体，有**正面**、**背面**
和**侧面**，还有放大的**局部区域**（面部、颈部、胸腹部、背部、上臂、前臂与手、
手、小腿与足部——每个都分左右侧）。在 *视图* 框中选择视图或区域。在简单
级别，同一幅示意图显示为“电极位置 (人体示意图)”。

**放置电极。** 点击 *添加电极*，然后点击人体。该点会**吸附到最近肌肉的推荐
位置**（按 SENIAM 参考的肌腹；面部为：咬肌、颞肌、额肌、眼轮匝肌和颧肌），
或者停留在您点击的地方。每个电极是一个带编号的点；拖动可移动，双击可重命名，
*Delete* 键可删除。放在放大区域中的电极也会显示在完整人体上。

**查看激活。** 检查过程中，肌肉的强度显示**在电极点上**，呈现为一团随强度
增大并升温的热斑（蓝 → 黄 → 红），并按人体轮廓裁剪。编号周围的圆环显示
信号质量。

在以前版本中制作的电极布置仍然有效：电极会转换到新的示意图上，不会丢失
肌肉、通道或名称。
