# 只显示使用中的通道

> 用户手册 → “肌肉检查”一章 → “肌肉活动（通道 × 时间）”一节的注释；以及“滤波与通道”一章 → “通道数”中的注释。

通道列表以及每行显示一个通道的图（随时间变化的肌肉活动、肌肉频谱图的通道、
疲劳的通道、心脏的通道、眼睛的水平与垂直通道、ERP 和自定义布局的通道、
阻抗表）只显示设备上**正在使用的通道**——8、16、32 或 64 个——并且只显示
类型正确的通道（例如，只显示标记为肌肉的通道）。以前，使用 8 个肌肉通道时，
活动图会从 CH1 一直列到 CH64。

当您更改通道数（在 *连接* 中或主屏幕上）或某个通道的类型（在 *滤波与通道*
中）时，这些列表会自动重建，并保留原来选中的通道（如果它仍在使用中）。
在 *回看一条记录* 中，列表跟随已打开记录的通道，而不是设备的通道。
