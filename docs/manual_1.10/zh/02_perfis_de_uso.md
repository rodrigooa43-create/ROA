# 使用配置：您从事哪类检查

> 用户手册 → “首次使用”一章 → 在“语言与级别”之后新增一节；以及“主屏幕”一章 → 新增“配置”一节。

只做一种检查的人不需要看到其他检查的界面。**使用配置**说明您从事哪类检查，
并决定：

- 主屏幕提供哪些检查（以及 *更改* 对话框）；
- 程序窗口中显示哪些标签页；
- 在完整级别，哪些图表（面板）默认打开。

**预设配置：** *大脑 (EEG)*、*肌肉 (EMG)*、*心脏 (ECG)*、*眼睛 (EOG)* 和
*全部*。*全部* 配置不隐藏任何内容：就像程序一直以来的样子。已经在使用 ROA
的人更新后仍然处于 *全部*。

**首次使用时**，*您从事哪类检查？* 页面显示四张大卡片（大脑、肌肉、心脏、
眼睛）。勾选您使用的所有项目：

- 一张卡片 → 该检查的预设配置；
- 两张或三张 → 个性化配置 *我的工作台*，只包含这些检查；
- 四张全选 → *全部*。

在完整（研究）路径中还有 *选择图表* 页面：为您的配置推荐的图表已经勾选好；
不想看的就取消勾选。之后随时可以通过每个标签页的 *面板* 按钮更改。

**切换配置。** 主屏幕上有 *配置：* 一行（两个级别都有）。切换立即生效：
配置之外的检查从屏幕上消失；如果正在使用的检查不在新配置中，程序会切换到
新配置的第一个检查。在 *系统 → 设置 → 主题与颜色 → 使用配置* 中，您还可以
**新建、复制、重命名和删除**配置，并勾选个性化配置包含的检查（预设配置不能
重命名或删除；请复制一份再编辑）。

**其他检查的记录。** 在 *打开录制* 中打开用其他类型检查做的记录仍然正常
可用，即使该检查不在您的配置中。
