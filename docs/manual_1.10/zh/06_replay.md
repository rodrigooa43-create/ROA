# 回放：把记录看成一段动画

> 用户手册 → “回看一条记录”一章 → 新增“回放”一节（在“PDF 报告”之后）。

打开一条**肌肉**、**心脏**或**眼睛**的记录时，**▶ 回放**按钮变为可用（对大脑
的记录它是禁用的）。它会打开一个窗口，其中的播放器对三种检查通用：
**▶ 播放 / ⏸ 暂停**、**⏮ 开头**、可拖动的时间线，以及“0:05 / 0:30”的时钟。
在完整级别还有速度（0.25× 到 4×）和 *循环*。

> 动画**模拟**的是所记录的内容：它不是患者的视频，不是报告，也不是诊断。
> 窗口顶部的标记会重复这一点。

## 肌肉

一个侧视的关节人形（躯干、肩、肘、前臂、腕、带手指的手）重现时间线上
**标记的动作**，每块肌肉按当时测得的强度亮起。旋后和旋前一目了然：浅色的
掌心朝上，或手背朝下，并配有文字“掌心向上/向下”。

时间线（2 到 4 条轨道）来自记录的**标记和阶段**（“屈曲”、“伸展”、“静息”…）；
没有标记时，**检测到的收缩**会变成“待定”片段。同一时刻的多条轨道会**叠加**
（例如，肘部屈曲的同时握紧手）。可用的动作：肘关节屈曲和伸展、旋后、旋前、
腕关节屈曲和伸展、张开手和握紧手、捏取、肩关节屈曲和伸展、静息。

在**简单**级别，您看到播放器、人形和片段列表。在**完整**级别，时间线可以
编辑：拖动一个块来移动它，拉边缘来拉伸，右键点击可*更换动作*、*在此拆分*、
*删除*、*添加/移除轨道*；Ctrl+Z 撤销。*预设任务*从光标处插入一段手握物体的
动作序列：**举哑铃**、**用钥匙开/关门**、**从桌上拿起杯子送到嘴边**。当活跃
的肌肉与所选动作不符时（例如，屈曲片段中肱三头肌活跃），会出现提示。
*保存*把 `movimentos.json` 写在记录旁边；关闭时，如有未保存的标注，程序会
询问。

## 心脏

一颗绘制的心脏**按记录的节律跳动**，旁边是带光标的描记和每分钟心跳数。
下方的条带显示**所有**心跳：规则心跳是一条细线；**提前心跳**是橙色三角形；
**较长停顿**是红色空心矩形（颜色加形状，方便色觉障碍者辨认）。文字列表
（“0:13 提前心跳”、“0:25 较长停顿（1.7 s）”）可以点击，并把播放器带到那个
位置。这些心跳与 PDF 报告中的相同。在完整级别，在条带上右键点击可以**修正**
（移除心跳、在此添加心跳、标记为规则 / 提前 / 较长停顿）；*保存*写入
`batidas.json`。

## 眼睛

两只绘制的眼睛**在眨眼时眨眼，并朝信号指示的方向看**。*水平反转*和
*垂直反转*交换方向，以应对电极贴反的情况。时间线用文字说明发生了什么
（“0:03 眨眼”、“0:05 向右看”），计数器累计眨眼以及向两侧和上下的运动。
在完整级别，在列表上右键点击可移除一个事件或更改方向；*保存*写入
`olhos.json`。
