# Textos-fonte dos manuais — novidades da 1.10.0

Os manuais do ROA (Manual do Usuário em 9 idiomas e Manual Técnico) são
montados fora deste repositório, no Windows. Esta pasta guarda os **textos-fonte
das seções novas da 1.10.0**, para serem copiados para os manuais na hora de
publicar:

- `pt/` — seções do Manual do Usuário em português (uma por pedido);
- `<idioma>/` — as mesmas seções traduzidas (en, es, it, fr, zh, de, ja, ru);
- `tecnico/` — seções do Manual Técnico (só em português, como o manual).

Cada arquivo começa com o título da seção e diz onde ela entra no manual
("Capítulo … → depois de …"). As capturas de tela citadas estão listadas em
`RETOMADA.md` (fotos a refazer no Windows).
